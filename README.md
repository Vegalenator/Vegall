# Шкатулка Мракса

Интерактивный квест-сайт по вселенной Гарри Поттера для тех, кто читал книги, а не пересматривал экранизации. Семь механических испытаний в одной латунной шкатулке — визуальный ориентир — игра *The Room*: тёплый металл, дуб, свеча, ни одного лишнего интерфейсного элемента.

Никаких зависимостей, сборщиков и бэкенда. Открывается двойным кликом по `index.html`.

## Что внутри

| № | Испытание | Механика |
|---|-----------|----------|
| — | **Порог** | Распределяющая шляпа: четыре вопроса, факультет задаёт акцентный цвет всего сайта |
| I | **Замок Гринготтса** | Три латунных барабана: колесо мыши, стрелки, цифры с клавиатуры |
| II | **Экзамен ЖАБА** | 10 вопросов по 25 секунд, бонус за скорость, разбор после каждого ответа |
| III | **Семь склянок** | Логическая задача с единственным решением; пометки мелом под склянками |
| IV | **Карта Мародёров** | Свет палочки за курсором проявляет имена на пергаменте |
| V | **Имя на крышке** | Анаграмма: 15 букв собираются в новое имя |
| VI | **Семь осколков** | Сопоставление крестражей с теми, чья рука их уничтожила |
| VII | **Зеркало Еиналеж** | Итог: ранг, баллы, время, журнал испытаний |

Логика третьего испытания проверена перебором: при пяти подсказках расстановка `яд · вино · вперёд · яд · яд · вино · назад` — единственная возможная.

## Интерактив и динамика

- **Свет палочки** следует за курсором и ложится поверх сцены; на карте он и есть инструмент поиска.
- **Звук** синтезируется на месте через WebAudio — щелчки барабанов, удары дерева, засовы. Ни одного медиафайла в репозитории.
- **Пепел и искры** — фоновый canvas; вспышки при верных ответах.
- **Заклинания.** Клавиша `~` (или `ё`) открывает строку. Шкатулка знает семь слов:

  | Слово | Действие |
  |-------|----------|
  | `Люмос` / `Нокс` | больше света / темнота |
  | `Акцио` | подсказка текущего испытания (со штрафом) |
  | `Алохомора` | вскрыть замок нечестно, −60 баллов |
  | `Экспекто Патронум` | серебряный патронус проходит по комнате |
  | `Сектумсемпра` | для врагов |
  | `Обливиэйт` | стереть прогресс |

- **Прогресс сохраняется** в `localStorage`: закрыли вкладку — вернётесь на то же место.
- Учтены `prefers-reduced-motion`, клавиатурная навигация, мобильные экраны и печать.

## Механизм семи книг

Второй раздел репозитория — `atlas/`: горизонтальная схема связей всех семи книг. Не квест, а чертёж: семь книг-барабанов на одном приводном валу, шесть сюжетных тяг, 77 узлов и 80 досье героев, существ, предметов и мест.

| Что | Как устроено |
|-----|--------------|
| **Линии** | Гарри и друзья · Тёмный Лорд · Орден и Дамблдор · Хогвартс · Министерство · Крестражи и Дары |
| **Навигация** | колесо мыши смещает вправо, перетаскивание — панорама, `Shift`+колесо — вертикаль, клавиши `1`–`7` — переход к книге |
| **Узел** | клик по карточке открывает разбор события; иконки под ней — досье героев и предметов |
| **Связи** | сплошная латунь — ход сюжета, пунктир кармином — тёмная нить, штрих патиной — отголосок, раскрытый позже |
| **Фильтры** | тумблеры линий гасят дорожку и пересобирают схему; поиск подсвечивает узлы и прыгает к первому совпадению |
| **Обзор** | латунная рейка внизу — вся схема целиком, клик по ней переносит взгляд |

Вся графика — рукописные SVG-гравюры (около шестидесяти символов в медальонных рамах), ни одного растрового файла и ни одной внешней картинки. Шрифты: Old Standard TT, Spectral, Oswald, Caveat.

```bash
python3 build/atlas.py     # atlas/atlas.artifact.html → atlas/index.html
```

Правки содержания — в `atlas/atlas.artifact.html`: массив `CARDS` (досье) и `NODES` (узлы сюжета, их книга, линия, колонка и связи).

## Структура

```
index.html              разметка и SVG-символы
assets/css/main.css     оформление: токены материалов, камеры, адаптив
assets/js/data.js       всё содержание: вопросы, ответы, разборы, стоимость ошибок
assets/js/audio.js      синтез звука механизмов
assets/js/fx.js         пепел, свет палочки, вспышки
assets/js/chambers.js   семь испытаний
assets/js/app.js        состояние, переходы, счёт, заклинания
atlas/atlas.artifact.html   схема связей семи книг: стили, гравюры, данные, логика
atlas/index.html            собранная страница схемы
build/atlas.py              сборка страницы схемы
build/inline.py         сборка однофайловых версий в dist/
```

Правки содержания — почти всегда в `data.js`: тексты вопросов, варианты, разборы и цена подсказок вынесены туда целиком.

## Сборка одного файла

```bash
python3 build/inline.py
```

Кладёт в `dist/` две версии: `quest.html` (самодостаточная страница) и `artifact.html` (тело страницы для публикации).

## Правовая заметка

Некоммерческий фанатский проект. Все имена, названия и элементы вселенной принадлежат их правообладателям; тексты вопросов, разборов и головоломок написаны для этого сайта.

## Терминал ИИ-цикла

Третий раздел репозитория — `terminal/`: рабочий терминал для отслеживания
инвестиционного и финансового цикла ИИ. Девять экранов, граф денежных связей с
автоматическим поиском круговых контуров, панель из 28 показателей со стресс-сигналами,
сценарный счётчик и отдельный контур по России. Каждая цифра несёт статус — факт,
оценка, прогноз или заявление руководства — и код первичного источника.

```bash
python3 build/terminal.py     # terminal/dist/artifact.html — однофайловая версия
```

Подробности и порядок обновления данных — в `terminal/README.md`.
