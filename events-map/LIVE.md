Ты ведёшь «Карту событий» в режиме «идёт» — для ведущего вечернего шоу на деловом радио. Страница: https://claude.ai/artifact/QzU5btiQM5G2J1CVWQjacW. Работай только с базой артефакта через ArtifactData (загрузи через ToolSearch: "select:ArtifactData,WebSearch,WebFetch"); страницу не перепубликуй, в git ничего не коммить. Этот прогон запускается каждый час и должен быть быстрым.

## Что делать
1. Определи текущее московское время. Прочитай коллекцию `events` (action list, query.limit 1000).
2. Отбери события, которые идут прямо сейчас: dateStatus не cancelled, start ≤ сейчас, и сейчас < end (если end нет: start + 2 часа; для allDay — конец дня start). Многодневные форумы идут все дни от start до end. Если таких событий нет — ничего не пиши и заверши работу.
3. Для каждого идущего события найди, что прозвучало с момента последней проверки (поле liveCheckedAt; если его нет — с начала текущего дня события):
   - главные заявления ключевых участников — первых лиц, министров, глав ЦБ и компаний: только значимые для России, бизнеса и рынков;
   - источники по порядку: стенограммы и сайты организаторов (kremlin.ru, government.ru, mid.ru, сайт форума), затем ленты Интерфакса, ТАСС, РИА Новости, РБК, Reuters, Bloomberg — у них заявления выходят отдельными молниями по ходу выступления.
4. Допиши новые заявления в statements (передай массив целиком: старые + новые) по схеме {date "YYYY-MM-DD", who, role, kind "quote"|"paraphrase", text, source {name,url}}. Не дублируй уже записанное — сверяй по who и смыслу. quote — только дословная прямая речь из источника, без кавычек внутри text; иначе paraphrase. Не выдумывай цитат. Не больше 8 заявлений от одного события за прогон — бери самые сильные.
5. Если появились существенные заявления — перепиши airBrief в настоящем времени, радийным языком: сначала 1–2 фразы, что происходит, затем 2–4 ключевых заявления с именем говорящего — сильнейшие дословные цитаты в кавычках «…», остальное пересказом. Объём можно расширять до 8–10 коротких фраз. Отметь в statements полем key: true 2–4 самых важных заявления события целиком (пересматривай отметки, когда появляются более сильные) — они попадут в итог в разделе «История». Если событие изменилось по факту (началось позже, перенесено, отменено, объявлены итоговые решения), исправь время или статус и допиши запись в changes {at, kind date|time|status|cancel|other, from, to, note, source}.
6. В каждом идущем событии обнови liveCheckedAt — текущее время ISO +03:00 (страница показывает «последняя проверка»), даже если нового не нашлось.
7. Пиши одним батчем (action batch) с if_version из прочитанных версий; при конфликте перечитай документ, объедини и повтори.
8. Только если что-то добавил — в `meta/status` (update с if_version) добавь в начало log запись {at:"ДД.ММ ЧЧ:ММ", text:"идёт: <событие> — заявлений +N"}; lastRunAt не трогай; храни не больше 20 записей.

Итоги закончившихся событий (outcome) пишет основной прогон в 06:47, 15:47 и 22:47 — здесь их не заполняй.
