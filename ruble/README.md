# Резервуар рубля

Интерактивная изометрическая фигура: валютный рынок как гидравлическая машина. Сделана по методу скилла [Anatomy](https://github.com/wheresryan22/anatomy) (копия его кита лежит в `kit/`, лицензия MIT).

- **Резервуар** — предложение валюты; поплавок крутит стрелку «₽ за $».
- **Насос «Экспорт»** — приток валюты; пульт с двумя ручками задаёт цену нефти и физический объём экспорта, **задвижка «Санкции»** срезает часть выручки.
- **Сливы «Импорт» и «Капитал»** — шаровой кран задаёт спрос на импорт, задвижки обоих сливов висят на траверсе ключевой ставки.
- **Насос Минфина и бак ФНБ** — бюджетное правило: подвижная метка цены отсечения и ручка масштаба операций на пульте «Правило».
- **Бак «Резервы ЦБ»** — продажи валюты из резервов Банка России через отдельную задвижку.
- **Самописец** — история курса на ленте.

Восемь регуляторов на панели: нефть, объём экспорта, санкционное трение, спрос на импорт, ключевая ставка, цена отсечения, операции Минфина, продажи ЦБ.

Модель условная (`model.mjs`): показывает направления и порядок связей, а не прогноз.

```bash
node ruble/build.mjs          # → ruble/index.html (открывается двойным кликом) и ruble/artifact.html
node ruble/build.mjs --audit  # проверка геометрии китом Anatomy
```

Файлы: `build.mjs` — геометрия, `live.js` — анимация и панель, `model.mjs` — модель, `ruble.css` — стили.
